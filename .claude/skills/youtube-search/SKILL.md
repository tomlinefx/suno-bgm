# YouTube BGM検索 → Sunoプロンプト生成スキル

YouTube で再生数が伸びているBGM動画を検索・分析し、Suno Advanced モード向けプロンプトを自動生成します。

## ユーザーの入力

$ARGUMENTS

---

## 動作フロー

### STEP 1: 検索条件の確認

引数がある場合はそのキーワードで検索。ない場合は「作業用BGM」をデフォルトキーワードとして使用。

検索前にユーザーへ条件を確認する：

```
🔍 YouTube検索条件
━━━━━━━━━━━━━━━━━━━━━━━━━━━
キーワード  : [キーワード]
フィルター  : アップロード日 = 今月
並び替え    : 関連度順（YouTubeデフォルト）
除外        : ライブ配信中の動画
抽出対象    : 再生数1,000以上の動画
━━━━━━━━━━━━━━━━━━━━━━━━━━━
この条件で検索しますか？
```

---

### STEP 2: ブラウザでYouTube検索

#### 2-1. ブラウザツールの準備
以下の順で必ずツールを読み込んでから使用する：
1. `ToolSearch` で `mcp__claude-in-chrome__tabs_context_mcp` を取得
2. `mcp__claude-in-chrome__tabs_context_mcp` でタブ状況を確認
3. `ToolSearch` で `mcp__claude-in-chrome__tabs_create_mcp`, `mcp__claude-in-chrome__navigate`, `mcp__claude-in-chrome__get_page_text`, `mcp__claude-in-chrome__find` を取得

#### 2-2. 検索URL

```
https://www.youtube.com/results?search_query=[URLエンコードしたキーワード]&sp=EgIIAxAB
```

sp パラメータ（単体のみ使用。複合は二重エンコードになるため禁止）：
- `EgIIAxAB` = アップロード日: 今月
- `EgIIAhAB` = アップロード日: 今週
- `EgIIARAB` = アップロード日: 今日

#### 2-3. ブラウザ操作の注意事項

| 問題 | 対策 |
|------|------|
| ref_ID の期限切れ | クリック前に毎回 `find` で ref を再取得する |
| フィルターが「今年」になる | `find` で「今月」を検索して ref を取得してからクリック |
| sp パラメータの二重エンコード | 複合URLを自作しない。単一パラメータのみ使用 |
| `javascript_tool` がブロックされる | `get_page_text` か `read_page` で代替 |
| スクリーンショットが真っ白 | `scroll_to` や `wait` を挟んでから再撮影 |

#### 2-4. 手順

```
1. tabs_create_mcp → 新規タブ作成
2. navigate → 検索URLに遷移
3. 2秒 wait
4. get_page_text → 結果テキスト取得
5. 結果が少ない場合は find「検索フィルタ ボタン」→ クリック
   → find「今月」→ クリック → 2秒 wait → get_page_text
```

---

### STEP 3: 検索結果の抽出・整理

取得したテキストから以下を抽出する：

- チャンネル名
- 動画タイトル
- 再生数（「〇〇万回視聴」「〇〇回視聴」「〇〇人が視聴中」）
- 投稿日時（「〇日前」「〇時間前」「に配信済み」）
- 動画の長さ（長尺=ループ系かどうかの判定に使用）
- ライブ配信かどうか

**フィルタリング条件：**
- ライブ配信中（「ライブ」表示）は除外
- 再生数1,000未満は除外
- スポンサー広告は除外

抽出結果をユーザーに提示：

```
## 検索結果：[キーワード]（今月）

| # | チャンネル | タイトル（省略） | 再生数 | 投稿日 |
|---|---|---|---|---|
| 1 | [チャンネル] | [タイトル] | [再生数] | [N日前] |

検索結果からテーマをランダム選択してSunoプロンプトを生成します。
```

---

### STEP 4: 4テーマのランダム選択 → Sunoプロンプト生成（合計2時間分）

#### 4-1. テーマのランダム選択

検索結果から、**ムードやジャンルが重複しないよう** 4テーマをランダムに選ぶ。

選定の多様性ルール（重複禁止）：
- ジャンルが被らない（例: ジャズ・ローファイ・ボサノバ・シティポップ など）
- 時間帯イメージが被らない（朝・昼・夜・深夜 など）
- テンポ感が被らない（スロー・ミドル・アップ など）

#### 4-2. 2時間分の曲数計算

```
目標合計再生時間 : 2時間 = 120分
テーマ数         : 4
1テーマあたり    : 30分
1曲あたりの尺    : 約3.5分（Sunoの平均生成尺）
1テーマに必要な曲数: 約9曲
合計曲数         : 約36曲（5回生成 × 4テーマ）
```

#### 4-3. プロンプト生成ルール

1. **英語で出力** — Sunoは英語プロンプトが最も安定して機能する
2. **アーティスト名は使わない** — スタイルを言葉で表現する
3. **楽器名を具体的に** — 「guitar」より「fingerpicked acoustic guitar」
4. **Styles欄は120文字以内**
5. **ムードは形容詞で** — 「happy」より「euphoric and uplifting」

#### 動画情報からの推定マッピング

| 動画の特徴 | 推定パラメータ |
|---|---|
| タイトルに「カフェ」「コーヒー」 | café ambience, acoustic guitar, soft piano |
| タイトルに「ジャズ」「Jazz」 | jazz piano, upright bass, brushed drums |
| タイトルに「ボサノバ」「Bossa Nova」 | bossa nova, nylon string guitar, soft percussion |
| タイトルに「Lo-fi」「ローファイ」 | lo-fi hip hop, dusty drums, mellow piano, vinyl crackle |
| タイトルに「ピアノ」「Piano」 | solo piano, minimal arrangement |
| タイトルに「春」「桜」「4月」 | spring vibes, cherry blossom, warm and bright |
| タイトルに「夜」「深夜」「Night」 | late night, calm and introspective, dark ambient |
| 動画が4時間以上 | instrumental only, loop-friendly, seamless |
| 動画が10時間以上 | ultra-long loop, ambient, no distinct structure |
| 「途中広告なし」表記 | seamless, no break, continuous flow |

#### Style Influence・Weirdness の目安

| 用途 | Style Influence | Weirdness |
|---|---|---|
| 人気チャンネルの模倣・量産 | 80〜90 | 0〜10 |
| 似た雰囲気で少し差別化 | 60〜75 | 10〜25 |
| 新しい方向性を探る | 40〜55 | 30〜50 |

**作業用BGMは基本: Style Influence 80〜88 / Weirdness 3〜10**

### STEP 5: 結果を保存

検索結果とプロンプト（4テーマ分）をMDファイルとして保存する。

- 保存先: プロジェクトの `.claude/search_results/` ディレクトリ
- ファイル名: `[キーワード]_[YYYYMM].md`
- 内容: 検索結果一覧 ＋ 2時間プランサマリー ＋ 4テーマのSunoプロンプト全文 ＋ チャンネル傾向分析

保存後にユーザーへ通知する：
```
💾 保存完了
パス: .claude/search_results/[ファイル名]
内容: 検索結果 + 4テーマ × Sunoプロンプト（2時間分）
```
